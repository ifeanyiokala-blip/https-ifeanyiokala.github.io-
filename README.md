# Ifeanyi Tony Okala — Portfolio Website

Dark, map-first portfolio site. One self-contained page (`index.html`) plus
an `assets/` folder with project thumbnails and your resume PDF.

## Publish it free with GitHub Pages

1. Create a free account at https://github.com (if you don't have one).
2. Create a **new public repository** named exactly:
   `ifeanyiokala.github.io`
   (replace `ifeanyiokala` with your GitHub username — the repo name must
   match `<your-username>.github.io`).
3. Click **Add file → Upload files** and drag in:
   - `index.html`
   - the whole `assets/` folder (with its 4 images + resume PDF)
4. Click **Commit changes**.
5. Go to **Settings → Pages**. Under "Build and deployment", make sure
   Source is **Deploy from a branch**, Branch is **main**, folder **/ (root)**.
   Save.
6. Wait ~1–2 minutes, then open `https://ifeanyiokala.github.io` — your site
   is live. 🎉

## Updating it later

- Edit `index.html` in any text editor, re-upload it to the repo, and the
  live site updates automatically in a minute or two.
- To swap a project image, replace the file in `assets/` keeping the same
  file name (e.g. `flood-map.webp`).
